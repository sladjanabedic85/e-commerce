# React eCommerce App
 
React eCommerce App is a frontend web application that allows users to browse products, view product details, add products to the cart and review their order before checkout.
 
## Features
 
- Display all products
- View product details
- Add products to cart
- Change product quantity
- Remove products from cart
- Calculate total cart price
- Responsive layout
 
## Tech Stack
 
- React
- JavaScript
- React Router
- Context API
- CSS
- REST API
 
## Project Structure
 
```text
src/
├── components/
├── pages/
├── context/
├── services/
└── App.jsx
```
